HTML/CSS Tutorial

Hier werden wichtige CSS-Befehle dieser Website kurz erklärt.

display: flex

Stellt Elemente nebeneinander dar.

justify-content: center

Setzt die Elemente in die Mitte.

gap

Bestimmt den Abstand zwischen den Elementen.

background-color

Ändert die Hintergrundfarbe eines Elements.

color

Ändert die Farbe des Textes.

width

Bestimmt die Breite eines Elements.

height

Bestimmt die Höhe eines Elements.

border-radius

Macht die Ecken eines Elements rund.

object-fit: contain

Sorgt dafür, dass das ganze Bild sichtbar bleibt.

font-size

Bestimmt die Größe des Textes.

text-align: center

Setzt einen Text in die Mitte.

padding

Macht Abstand innerhalb eines Elements.
